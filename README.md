# AlumiLauncher

スマートフォンのホーム画面のように、アプリ・ファイル・フォルダをグリッドに並べて、クリックで起動できる Windows 用ランチャーです。
- フォルダ(ショートカットを入れた Windows のフォルダ)を、そのまま登録できます。ドラッグで並べ替え・フォルダ作りもできます。
- 画面の上下に、ウィジェット(時計・検索・ToDo・タイマーなど)を置けます。メモ・ミュージック・予定とToDo などの**ミニアプリ**も、ランチャーの中で動きます。
- ミニアプリ・ウィジェットは、HTML / JavaScript だけで自作できます([作り方](docs/extending.md))。

## はじめかた

1. [Releases](../../releases) から、次のどちらかをダウンロードします。
   - `AlumiLauncher_Setup.exe` … インストーラー(管理者権限は不要。「設定 → アプリ」からアンインストールできます)
   - `AlumiLauncher_Portable.zip` … インストール不要。解凍して、`AlumiLauncher.exe` を実行します(データは、フォルダの中の `data` に保存されます。消すときは、フォルダを削除するだけです)
2. 初めて実行すると、「Windows によって PC が保護されました」と出ることがあります。コード署名をしていないためです。**「詳細情報」→「実行」** で続行できます。
3. 起動すると、ホーム画面が出ます。**`Ctrl+Alt+L`** で、表示と非表示を切り替えられます(設定で変えられます)。タスクトレイにも、常駐します。

## かんたんな使い方

### アイコン・フォルダを追加する
- **フォルダを、ウィンドウにドラッグ&ドロップ** … ホームに、そのフォルダが追加されます。
- **ショートカット・exe・ファイルを、ウィンドウにドロップ** … ホームに、アイコンとして並びます。**ファイルは、元の場所から移動されます**(元の場所には、残りません)。
- 右下の **＋** → **「スタートメニューから追加」** … Windows のスタートメニューにあるアプリ(ストアアプリも)を、一覧から選んで追加します。ショートカットが**複製**されるので、元のアプリは、そのままです。
- ホームで **右クリック** … 空のフォルダや、空のテキストファイルを作れます。

### 並べ替える・整理する
- アイコンを **長押ししてドラッグ** … 並べ替えます。
- アイコンを、別のアイコンの**中央に重ねて、少し止めて離す** … 新しいフォルダができて、2 つが入ります。
- アイコンを、**フォルダの中央に重ねて離す** … フォルダに入ります。
- **右クリック** … アイコンは、「プログラムから開く」「ファイルの場所を開く」「プロパティ」など。フォルダは、「名前の変更(表示名だけ)」「エクスプローラーで開く」「一覧から外す」など。
- **`Ctrl+Z` / `Ctrl+Y`** … 並べ替えや、フォルダの作成・名前の変更などを、元に戻す・やり直す。
- ウィンドウの外へ、アイコンをドラッグして出すと、デスクトップやエクスプローラーのフォルダへ**移動**できます。

### ウィジェットとミニアプリ
- **＋** → **「ウィジェットを追加」** … 画面の上(ヘッダー)か下(フッター)に、置けます。ウィジェットは、長押ししてから動かして、好きな場所へ移せます。右クリックで、幅を変えたり、外したりできます。ヘッダー(フッター)の高さ(小・標準・大)は、ヘッダー(フッター)の空いている所を右クリックして選びます。
- **＋** → **「ミニアプリを追加」** … メモ、ミュージック、予定とToDo などの、小さな道具を開けます。ホームにアイコンとして置くこともできます。

### 画面の切り替え・設定
- 左上の **数字ボタン(1〜3)**、数字キー **1〜9**、**`Alt+←` / `Alt+→`** … フォルダとアイコンの組み合わせ(プリセット)を、切り替えます。
- 右下の **歯車** … 画面の大きさ、背景、アイコンの大きさ・間隔、ショートカットキー、自動起動などの設定です。
- **キーボード** … 矢印キーで選んで、`Enter` / `Space` で開きます。`R` / `F5` で再読み込み、`Esc` でフォルダを閉じる・ウィンドウを隠す、です。

## 知っておいてほしいこと
- **アプリ自身は、外部と通信しません。** ミニアプリで、外部の Web サイトに接続することもできますが、**作者は推奨していません**(自分の責任で、信頼できるサイトだけにしてください)。
- **デスクトップモード**(設定の「ウィンドウ」)は、ウィンドウを最大化して、一番後ろに固定するだけの、**疑似的な**ものです。Windows のデスクトップそのものの置き換えでは、ありません。
- 設定は、`%AppData%\AlumiLauncher\config.json` に保存されます(ポータブル版は、`data` フォルダの中)。失敗やエラーの記録は、`%AppData%\AlumiLauncher\logs\alumi.log` に残ります。この PC の外へは、送りません。
