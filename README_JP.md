# AlumiLauncher

日本語 | [English](README_EN.md)

## AlumiLauncher とは

スマートフォンのホーム画面のように、アプリ・ファイル・フォルダを**グリッドに並べて、クリックで起動**できる Windows 用ランチャーです。
フォルダ(= ショートカットを入れた Windows のフォルダ)をそのまま登録でき、アイコンのドラッグで並べ替え・フォルダ作りができます。
画面の上下にウィジェット(時計・検索・ToDo・タイマーなど)を置け、メモ・ミュージック・予定とToDo などの**ミニアプリ**も、ランチャーの中で動きます。
ミニアプリ・ウィジェットは、HTML / JavaScript だけで自作できます([作り方](docs/extending.md))。

**こんな人に**: ショートカットが散らかったデスクトップを、すっきり整理したい人 / よく使うアプリ・フォルダを、1 つの画面に集めたい人 / 小さな道具(メモ・タイマー・音楽プレーヤー)を、1 つのアプリにまとめたい人。

### 特長

- 完全ローカルで動作します(外部との通信は、想定していません。通信するウィジェット・ミニアプリは、宣言と、初めて使うときの同意が必要です。詳細は「外部通信について」)
- Tauri 2(Rust)+ React / TypeScript。小さく軽量
- ショートカットで表示/非表示(既定は `Ctrl+Alt+L`。設定で、好きな 2〜3 キーに変えられます)、タスクトレイに常駐、Windows 起動時の自動起動(初期はオフ。設定でオンにできます)
- ドラッグ&ドロップでフォルダ・ショートカットを追加、ドラッグで並べ替え、フォルダ名の変更(元のフォルダ名は変わりません)
- 背景(色・ライト/ダーク・画像・透過度)、アイコンの大きさ/間隔/表示数、表示言語(日本語/英語)は Windows の設定に従う

## 動作環境

| 項目 | 必要 | 目安・備考 |
|---|---|---|
| OS | **Windows 10 / 11(64 ビット)** | Windows 11 で開発・動作確認しています。Windows 10 は、動作する見込みですが、実機では未確認です |
| WebView2 ランタイム | 必要 | Windows 11 と、最近の Windows 10 には入っています。無ければ、通常版のインストーラーが取得します |
| CPU | 64 ビット(x64)の CPU | ARM 版の Windows は、未確認です |
| メモリ | 4GB 以上(推奨 8GB 以上) | アプリ本体と WebView2 を合わせて、約 270MB を使います(Windows 11・起動直後に 1 回、実測) |
| ストレージ | 空き 100MB 以上 | インストールは数十 MB。オフライン版のインストーラーは約 210MB。ログ・ミニアプリのデータは、使うほど増えます |
| 画面 | 1280×720 以上を推奨 | 最小のウィンドウは 240×60 まで小さくできます。複数のディスプレイでの「デスクトップモード」は、未対応です |

インターネットへの接続は、使うときには要りません(WebView2 が入っていない PC に通常版を入れるときだけ、取得します)。

## インストール

[Releases](../../releases) から、次のどれかをダウンロードして使います。

| ファイル | 内容 |
|---|---|
| `AlumiLauncher_Setup.exe` | 通常版(約 3.5MB)。Windows 11 には WebView2 が入っているため、通常は通信しません |
| `AlumiLauncher_Portable.zip` | ポータブル版。インストール不要。解凍して `AlumiLauncher.exe` を実行します。データは、フォルダの中の `data` に保存されます(消すときは、フォルダを削除するだけ) |
| `AlumiLauncher_Setup_Offline.exe` | オフライン版(約 210MB)。WebView2 を同梱し、インストール中も一切通信しません |

管理者権限は不要です(ユーザー単位でインストールされ、「設定 → アプリ」からアンインストールできます)。

### SmartScreen の警告について

インストーラーにはまだコード署名がないため、初回に「Windows によって PC が保護されました」と表示されることがあります。
**「詳細情報」→「実行」** で続行できます。心配な場合は、`SHA256SUMS.txt` と照合してください。

```powershell
Get-FileHash .\AlumiLauncher_Setup.exe -Algorithm SHA256
```

表示されたハッシュが `SHA256SUMS.txt` の値と一致すれば、配布されたファイルのままです。
ソースはこのリポジトリにあり、自分でビルドすることもできます。

### WebView2 について

画面の表示に Microsoft Edge WebView2 ランタイムを使います。Windows 11 と最近の Windows 10 には標準で入っています。
入っていない PC では、通常版が Microsoft から取得してインストールします(オフライン版は同梱なので通信しません)。

## 使い方

- ショートカットキーは設定の「起動」で変えられます。「変更」を押してから、割り当てたいキーを押して離します。**Ctrl / Alt / Shift のどれかから始めて、2〜3 キー**で指定します(例: `Ctrl+Space`、`Ctrl+Alt+L`)。「修飾キー+キー+キー」(例: `Alt+Space+L`)は、最初の 2 キーを押してから約 1.5 秒以内に 3 つ目のキーを押す 2 段階になります。他のアプリが使っている組み合わせは、登録できないため元のままになります。`Alt+Space` を使う組み合わせにすると、Windows 標準のウィンドウメニューの代わりにこのアプリが使います。使いたくない場合は、ショートカットを変えるか、オフにしてください。以前の既定だった `Alt+Space+L` のままだった場合は、更新したときに `Ctrl+Alt+L` へ付け替わります。
- 右下の **＋** … ホームではメニュー(フォルダを追加 / スタートメニューから追加 / ウィジェットを追加 / ミニアプリを追加)。フォルダを開いているときは、そのフォルダにファイルを追加
- ホームで **右クリック** … 「フォルダを作成」(空のフォルダ。作ったあと名前を付けられます)/「新規ファイルの作成」(空の `.txt`。ホームのアイコンとして並びます)/「ウィジェットを追加」
- フォルダを **ドラッグ&ドロップ** … ホームで、ドロップしたフォルダがそのまま一覧に追加されます
- ホームに **ショートカット・exe・ファイルをドロップ** … データ保持用フォルダ(`%AppData%\AlumiLauncher\launcherFolder`)へ**移動**され(元の場所からは無くなります)、フォルダではなく**アプリのアイコンとしてホームに直接**並びます(ドラッグで並べ替え可)
- **＋** →「スタートメニューから追加」 … Windows のスタートメニューにあるアプリ(通常のアプリも、ストアアプリも)の一覧から選ぶと、そのショートカットが、ホームに**複製**されて追加されます(スタートメニューの元のアプリは、そのままです)。名前で絞り込めます。スタートメニューからのドラッグ&ドロップは、Windows の仕組み上、受け取れないため、この画面を使ってください
- アイコンを **右クリック** … プログラムから開く(アプリを選んで開く)/ ファイルの場所を開く / プロパティ / ごみ箱へ移動(登録したフォルダ内のファイルのみ)
- フォルダを **右クリック** … 名前の変更(表示名だけ。元のフォルダ名は変わりません)/ エクスプローラーで開く / プロパティ / 一覧から外す
- アイコンを **長押ししてドラッグ** … 並べ替え
  - ホームで、アイコンを別のアイコンの**中央に重ねて(少し止めて)離す** … 新しいフォルダができて、2つが入ります
  - ホームで、アイコンを**フォルダの中央に重ねてすぐ離す** … フォルダの一番後ろに入ります
  - ホームで、アイコンを**フォルダの中央に重ねて少し待つ** … フォルダが開くので、そのまま好きな位置で離すと、その位置に入ります(スマートフォンのホーム画面と同じ操作)
  - フォルダ内で、アイコンを**枠の外へ出してすぐ離す** … ホームの一番後ろに置かれます
  - フォルダ内で、アイコンを**枠の外へ出して少し待つ** … フォルダ内の画面が薄くなるので、ホームの好きな位置で離すと、そこに置かれます(フォルダ内ではフォルダは作れません)
- **Ctrl+Z / Ctrl+Y** … 並べ替え・フォルダの作成/名前変更/一覧から外す・アイコンの移動を元に戻す/やり直す(それぞれ最大5件。ファイルの移動も戻ります)
- フォルダ内のアイコンをホームへ持ち出し(枠の外で少し待つ)、そのままホームのフォルダの中央に重ねて離すと、そのフォルダへ直接移動します
- フォルダへ入れる判定は広めです(フォルダのほぼ全体に重ねて、少し待つか離すと入ります)。ホームのアイコンどうしも、中央の 44% に重ねると新しいフォルダになります
- ファイル名は拡張子つきで表示します(例: `Google Chrome.lnk`)
- アイコンをドラッグしている間に **Shift** を押すと、自動の入れ替わりとページ送りを止めて、並びを固定します。アイコンを重ねてフォルダへ入れる・アイコンどうしを重ねてフォルダを作る操作は、Shift を押していても使えます
- ウィンドウの外へ移動 … ホームやフォルダの中のアイコン(ファイル)をドラッグしてウィンドウの外へ出すと、Windows 標準のドラッグに切り替わり、デスクトップやエクスプローラーのフォルダへ**移動**できます(登録したフォルダそのものは対象外)
- リアルタイム反映 … 登録したフォルダやホームの中身を、エクスプローラーなどで追加・削除・名前変更すると、リロードしなくても、すぐに一覧(フォルダのプレビューも)に反映されます
- UI の色 … 設定の「UI の色」で、時計・ボタン・フォルダ内・メニューなどの色を、背景とは別に選べます(背景と同じ/クリア/ダーク/ライト/Windows テーマ/好きな色。「クリア」は、すりガラスのように透けた見た目です)。透過度も別に設定できます。ホームのフォルダの板と、ウィジェットのカード(時計を除く)は、同じ色・同じ透過度にそろえています
- ツールチップ … ボタンなどにカーソルを合わせたときの説明は、既定では出しません。設定の「ウィンドウ」の「説明を表示する」(`showTooltips`)でオンにできます
- 画像・動画 … エクスプローラーの「大アイコン」と同じように、中身のプレビューで表示します(設定でオフにできます)
- 小さいウィンドウ … 最小は横 240px・縦 60px。高さ 200px 未満では、ヘッダー・フッターとラベルを消して、アイコンだけを詰めて並べます
- プリセット … 左上の数字ボタン(初期は 1〜3。設定で 1〜9 まで増やせます)、数字キー **1〜9**、または **Alt+←/→**(**Home / End** でも)で、フォルダとアイコンの組み合わせを切り替えます(それぞれ別々に登録・並べ替えできます)。今までの設定は 1 に入ります。設定でプリセットを使わないようにすると、1 を表示して、左上の切り替えを消します。プリセット 2 以降のホームのアイコンは `launcherFolder2`〜`launcherFolder9` に保存されます。Fn キーはキーボード側で処理されてアプリには届かないため、Fn キー自体は読み取れません。Fn+←/→ が Home / End になる、Fn+数字が数字キーになるキーボードなら、Fn を押しながらでも切り替えられます
- キーボード … **矢印キー**で選択を動かす(ページをまたぐと自動で切り替わり、選んだアイコンは光ります)/ **Enter・Space** で開く・起動 / **R・F5** で再読み込み / **Esc** でフォルダを閉じる・ウィンドウを隠す / **Ctrl+Z・Ctrl+Y** で元に戻す・やり直し
- 右下の歯車 … 画面サイズ、常に最前面に表示、表示数、アイコンの大きさ・間隔、背景、ドラッグ操作の時間、ショートカットキー、スタートアップの設定(「デフォルト値にする」で初期値に戻せます)

設定は `%AppData%\AlumiLauncher\config.json` に保存されます(ポータブル版は、exe の隣の `data` フォルダ)。

### 記録(ログ)

失敗やエラーは、`%AppData%\AlumiLauncher\logs\alumi.log` に書き残します(ポータブル版は `data\logs`)。256KB を超えると `alumi.log.old` に交代し、古い 1 世代だけ残ります(`logs` フォルダ全体で、約 0.5MB 以下)。**この PC の中だけに置き、どこにも送りません。** 設定を保存できなかったときは、画面にも知らせます。不具合を報告するときは、必要なら、この記録を添えてください(ファイルのパスなどが入ることがあるので、中身を確かめてから)。

## 画面の構成

画面は、上から順に、次の 5 つの段に分かれています。

| 段 | 内容 |
| --- | --- |
| **トップ** | いちばん上の帯。左にプリセットの切り替え(1 2 3)、右にウィンドウのボタン(最小化・最大化・閉じる) |
| **ヘッダー** | ウィジェットを並べる段。右クリックで高さ(小・標準・大)を決めます。ウィジェットが無ければ、出ません |
| **ホーム** | アイコン・フォルダを並べる、いちばん広い段。左右にページ送りができます |
| **フッター** | ウィジェットを並べる段。ヘッダーと同じです |
| **ボトム** | いちばん下の帯。右に ＋・再読み込み・設定のボタン |

高さが 380px 未満・幅が 300px 未満のウィンドウでは、ヘッダー・フッターは出ません。高さが 200px 未満では、トップ・ボトムの帯もなくなり、アイコンだけを詰めて並べます。ウィンドウの最小は、横 240px・縦 60px です。

## ウィジェット

画面の上(ヘッダー)と下(フッター)に、ウィジェットを並べられます。**＋**(または、ホームの右クリック)→「ウィジェットを追加」で、ヘッダー/フッターのどちらに出すかを選びます。ヘッダー・フッターは、**横に 7 マス**に区切られています(左から 1〜7、中心は 4)。マスは、アイコンと同じ**正方形**です(1 マスは **44px で固定**です。設定のアイコンの大きさでは、変わりません。ウィンドウが狭くて、7 マスが収まらないときだけ、縮みます)。ウィジェットは、決まったマスに置かれて、重なりません。ウィジェットを**長押し**(設定の「長押し」の時間)してから動かすと、好きなマスへ移動できます(ヘッダー・フッター間も可。動かしている間は、マスの区切りと、「いま離したらウィジェット全体が収まる場所」を囲む枠が出ます(置けない所は赤い枠)。短く押しただけなら、ふつうの操作です)。**高さ**は、ウィジェットではなく、**ヘッダー(フッター)を右クリック**して、**小(1 マス)・標準(2 マス)・大(3 マス)** から選びます(初めは標準)。ヘッダー(フッター)の中のウィジェットは、すべて、その高さになり、中身は、高さに合わせて切り替わります(たとえば、小(1 マス)のミュージックは、曲名と再生ボタンだけを 1 行に出します)。ウィジェットを動かしている間に出る、マスの目印(四角)も、その高さの数だけ縦に並びます(いつも正方形です)。追加ウィジェット(中の画面が別になっているもの)だけは、長押しが届かないので、マウスを乗せると出る左上の **⋮⋮** をドラッグして動かします。ドラッグの途中でスクリーンショットなどでウィンドウのフォーカスが外れたときは、移動を取り消します。ウィジェットを**右クリック**すると、幅(マスの数)の変更・反対側へ移動・外すができます。大きさの範囲はウィジェットごとに違います: 時計 1〜7・ショートカット 1〜7・よく使うもの / 最近開いた / 検索 / ToDo / ミュージック 3〜7・タイマー 4〜7・追加ウィジェット 1〜7(右クリックには、いまの場所の周りで実際に変えられる大きさだけが出ます)。置ける場所が無いときは、そう知らせます。ヘッダー・フッターは設定で使う/使わないを選べます。**高さ 380px 未満・幅 300px 未満のウィンドウでは、ヘッダー・フッターは表示されません。**

組み込み:

- **ショートカット** … ホームのアイコン・フォルダを、**ホームからドラッグして**入れておけるウィジェットです(元のものは、ホームに残ります)。押すと、アイコンは起動、フォルダは、ランチャーの中で開きます。**横は 6 個まで**で、ヘッダー(フッター)の高さが小・標準のときは **1 段**(6 個まで。標準は、アイコンを少し大きく表示)、大のときは **2 段**(12 個まで)です。ホームのアイコン・フォルダに加えて、**ミニアプリ**も入れられます。あくまで「ホームにあるものの近道」なので、**ホームから無くなったもの(消した・フォルダへ移した・一覧から外した)は、ウィジェットからも自動で外れます**(ミニアプリだけは、ホームではなく、ミニアプリのフォルダに無くなったときに外れます)。アイコンを**右クリック**すると登録を解除でき、アイコンを**ドラッグ**すると順番を変えられます。アイコンの名前を変えたり、別の場所へ移したりすると、ウィジェットからは開けなくなるので、いったん外して、入れ直してください

- **時計** … 時刻と日付(これまで画面上部にあった時計です。既定ではヘッダーに入っています)

- **よく使うもの** … 起動回数の多いもの上位 5 個(アイコンを押すと起動)
- **最近開いた** … 直近に起動したもの 5 個。この 2 つは、このアプリから起動した記録だけを使います(記録は `config.json` に最大 300 件)
- **検索** … 入力した文字で、ホームのアイコンを絞り込みます(フォルダ内のアイコン名にも当たります)。`/` か `Ctrl+F` で入力欄へ、Enter で最初に見つかったものを開く、Esc で解除。絞り込み中は並べ替えできません
- **ToDo** … ミニアプリ「予定とToDo」のデータから、「次にやること」(期限の近い順に 6 件まで)と、今日の予定を出します。チェックで完了にでき、入力欄から追加もできます(以前のウィジェットの ToDo が残っていれば、引き継ぎます)。「ToDo ↗」を押すと、ミニアプリが開きます
- **タイマー** … 集中 25 分 / 休憩 5 分 / 長休憩 15 分。終わると、音を鳴らして、ウィンドウを前に出して知らせます

ToDo・タイマーなどの内容は、設定ファイルではなく、それぞれのフォルダの `data` フォルダに保存されます(次の節)。「デフォルト値にする」では消えません。

### データとキャッシュ

ウィジェット・ミニアプリが保存するものは、それぞれのフォルダの中の 2 つのフォルダに入ります。

- `data` … 残しておくデータ(ToDo・メモの付箋・曲の一覧・タイマーの状態など)。キーごとに、`data\<キー>.txt` のファイルです
- `cache` … 消えても困らない、作り直せるもの(画像ビューアの見本画像 `miniapps\gallery\cache\thumbs` など。合計 200MB を超えたら、古いものから消えます)。URL を開くミニアプリ(試験的機能)の、ブラウザのキャッシュ(`data\webview` の中の Cache など)も、「キャッシュ」に数えます

「ウィジェットを追加」・「ミニアプリ…」の一覧の各行に、データとキャッシュの大きさと「消去」ボタンがあります(データの消去は、2 回押します)。一覧の下の「すべてのキャッシュを消去」「すべてのデータを消去」で、まとめて消せます。URL を開くミニアプリを開いている間は、そのデータ・キャッシュは消せません。ToDo ウィジェットのように、ミニアプリとデータを共有するウィジェットは、共有先のミニアプリ(予定とToDo)のデータを消します(`widget.json` の `data_app`)。

以前の版で、設定ファイル(`config.json` の `widgetData`)に入っていたデータは、更新後の最初の起動で、それぞれのフォルダの `data` へ自動で移ります。以前の URL を開くミニアプリの保存場所(`%LocalAppData%\AlumiLauncher\miniweb`)は、移りません(必要なければ、このフォルダを削除してください)。

## ミニアプリ

ランチャーの中で動くアプリです。開くと、**アプリ全体がそのミニアプリの画面**になります(左上の「‹ ホーム」で戻ります)。**＋** またはホームの右クリック →「ミニアプリ…」で、開く・ホームに追加(アイコンから開けます)ができます。

- 組み込み: **メモ** … 書いたメモを「保存してホームに追加」(または Ctrl+S)で、テキストファイル(`.txt`)としてホームに追加します。書きかけは残ります(以前のメモウィジェットは、ミニアプリになりました。ウィジェット一覧には出ません)
- 組み込み: **ミュージック** … パソコンの音楽ファイル(mp3 / flac / wav / ogg / opus / m4a / aac)を再生する音楽プレーヤーです。「ファイルを追加」「フォルダを追加(サブフォルダも探します)」で曲を入れます。再生 / 一時停止・前へ・次へ・再生位置のシーク・音量とミュート・シャッフル・リピート(なし / 全曲 / 1 曲)・速度(0.75〜2 倍)・おやすみタイマー(15 / 30 / 60 分)・プレイリスト(自分で作れるのは最大 8 個。先頭には、お気に入りの曲を集める「**マイリスト**」が必ずあります。曲の ♡ を押す(または、再生中の曲の ♡ か L キー)とマイリストに入り、♥ で外せます。マイリストは、消せず、名前も変えられません。新規・名前変更・削除・切り替え、曲の右クリックで別のプレイリストへコピー、クリックで再生・× で外す・ドラッグで並べ替え・クリア)があります。キー操作は、Space(再生 / 一時停止)・←→(5 秒移動)・↑↓(音量)・N / P(次 / 前)・M(ミュート)・Esc(閉じる)。Windows のメディアキーにも対応します。プレイリストと設定は保存され、次の起動で戻ります(曲は選ぶだけで、勝手には鳴りません。保存できる曲数は、パスの長さによって数百〜千曲ほどです)
  - プレーヤー本体はランチャー側にあるので、ミニアプリを閉じても再生は続きます。ウィジェット「ミュージック」(曲名・前へ / 再生 / 次へ・音量とミュート・再生位置。曲名を押すとミュージックが開きます)で操作できます
- 組み込み: **メモ** … 「メモ帳」と「付箋ボード」の 2 つの画面があります。メモ帳は、ホームの `.txt` / `.md` を一覧から開いて編集できます(1.2 秒ごとと、切り替え・閉じるときに自動で上書き保存。Ctrl+S でもすぐ保存)。「＋ 新しいメモ」で書いたものは、「保存してホームに追加」で `.txt` になります。付箋ボードは、色つきの付箋を並べられて(最大 30 枚)、ホームへ書き出せます
- 組み込み: **予定とToDo** … ToDo(期限・カテゴリ・完了済みの一覧・並べ替え・ダブルクリックで名前の変更)と、カレンダー(月表示。予定にメモを付けられます。ToDo の期限も、日付の点で出ます)
- 組み込み: **時計とタイマー** … 世界時計(時差つき)・ストップウォッチ(ラップ)・複数のタイマー・ポモドーロ(今日の集中時間・1 週間のグラフ・時間の設定)。タイマーなどの時刻は、ミニアプリを閉じていても、音と画面で知らせます
- 組み込み: **全体検索** … ホームと、登録したフォルダの中のアイコンを、まとめて名前で探して起動します(↑↓ で選んで Enter)
- 組み込み: **画像ビューア** … フォルダ(サブフォルダも)や、選んだ画像の一覧・拡大・スライドショー(2〜15 秒・ランダム)。前回のフォルダは、ランチャーが覚えます。一覧は、小さな見本画像を使うので、写真が多くても軽く動きます
- 組み込み: **ラッキーラッシュ** … パチスロ風のミニゲーム。通常時は、回すたびに「抽選に入るか」が決まり、入ると色(白・青 → 橙・緑 → 赤 → 金 → 虹)で当たりの期待度を見せます。当たると CHANCE(10 回転のうちに 1 回当たれば RUSH 確定)、RUSH は 100 回転を高速(約 0.2 秒)で回し、その間に当たれば継続(継続率 約 90%)。RUSH の連チャン数がスコアです。スロットの下(右側)に、「回転数」(前回当たってからの回転数。当たったときだけリセット)と、「ゲーム数」(RUSH で行った総ゲーム数。RUSH が終わると、結果にも出ます)を出します(ハイスコア・履歴(10件まで)・平均つき。AUTO / TURBO あり、画面の「?」で確率を確認できます)。音は、その場で作る単純な音で、音源ファイルは使いません。成績は、このミニアプリの `data` フォルダに保存されます。コインなどを賭けるものではありません
### ドラッグ&ドロップ

- 「ウィジェットを追加」の一覧の行を、ヘッダー・フッターへドラッグして追加できます(置いた位置に入ります)。ドラッグ中は一覧が透明になって、後ろが見えます
- 「ミニアプリ…」の一覧の行を、ホームへドラッグして、ホームにアイコンとして追加できます
- 一覧の「フォルダの場所を開く」で、`widgets` / `miniapps` フォルダを開けます

### フォルダのドロップで取り込む

ウィジェットのフォルダ(`widget.json` があるもの)やミニアプリのフォルダ(`miniapp.json` があるもの)を、ウィンドウにドロップすると、自動で `widgets` / `miniapps` フォルダへコピーされます(同じ名前は置き換え)。それ以外のフォルダは、今まで通り、ホームの一覧に追加されます。ファイルの数は 2000 個、合計 50MB までです。

## 音量

設定の「音量」で、ランチャーが出す音全体の音量(0〜100%、既定は 100%)を決められます。100% は、PC の音量設定のままです。ミュージックの再生に掛かります。URL を開くミニアプリは、ページが決めた音量に、この割合が掛かります(開いている最中に変えても反映されます)。ページが音量を決めずに音を出すサイトでは、効かないことがあります。
## 外部通信について

- このランチャーは、ミニアプリで外部サイトを開いたり、通信したりすることを想定していません。アプリ自身のコードは、ネットワーク通信を一切行いません(HTTP クライアントなどの依存もありません)。組み込みのウィジェット・ミニアプリも、通信しません。
- 通信が必要なウィジェット・ミニアプリ(自作のもの、URL を開くものなど)は、`"network": true` の宣言が必要です。初めて使うときに 1 回だけ警告が出て、同意すると次からは出ません(設定の「外部との通信を許可したもの」から取り消せます)。宣言していないもの、同意していないものは、通信できません。
- **同意すると、そのウィジェット・ミニアプリは、外部の https のサーバーから、プログラム(スクリプト)を読み込んで実行することもできます**(通信できる = 外部のコードを取り込める、ということです)。同意の画面にも、そのことを書いています。信頼できるものだけ、許可してください。
- 画面は CSP(Content Security Policy)で、自分自身のファイル以外の読み込み・通信を禁止しています。
- Microsoft の WebView2 ランタイムは、アプリとは別に Microsoft のサービスへ通信することがあります。
  これはアプリの外側の動作で、アプリからは完全には止められません。
- WebView2 が入っていない PC に通常版をインストールするときだけ、インストーラーが Microsoft から取得します。

## デスクトップモード

設定の「ウィンドウ」にある「デスクトップモード」をオンにすると、ランチャーを**デスクトップの代わり**に使えます(「常に最前面」の反対のイメージです)。

- 常に一番後ろに置かれます(ほかのウィンドウの後ろ)。画面をクリックすれば操作できて、そのときも一番後ろのままです。
- 最大化したまま固定されます(タスクバーは隠しません)。ドラッグ・ダブルクリック・Win+↓ などでは、動いたり元の大きさに戻ったりしません。
- 右上の「閉じる・最小化・最大化」のボタンは消えます。**Esc**・ショートカット・タスクトレイのクリックでも隠れず、アイコンを押しても最小化されません。
- 「常に最前面」は、デスクトップモードのあいだ、使えません(オフに戻すと、元の設定に戻ります)。
- **複数のディスプレイには対応していません**(ウィンドウがあるディスプレイにだけ広がります)。
- オフにすると、最大化が解けて、ふつうのウィンドウに戻ります。ランチャーを終えるときは、トレイのメニューか、設定の「アプリを終了する」を使ってください。

## 音について

アラームなどの音は、音源ファイルを使わず、アプリの中でその場で作った単純な音(正弦波)です。著作権・ライセンスの問題はありません。音のファイルを追加する場合は、CC0 または Windows に標準で入っているものだけを使ってください。

## よくある質問・困ったとき

| 質問 | 答え |
|---|---|
| データはどこに保存されますか | 設定・ホームのアイコン・ミニアプリ・ウィジェット・ログは `%AppData%\AlumiLauncher\` です(ポータブル版は、exe の隣の `data`)。ホームに置いたファイルは `launcherFolder` にあります |
| アンインストールするとデータは消えますか | 「設定 → アプリ」から消しても、データは残ります。完全に消すときは、`%AppData%\AlumiLauncher\` も削除してください |
| ショートカットキーが効きません | 他のアプリが同じ組み合わせを使っている可能性があります。設定の「起動」で別の組み合わせに変えてください |
| 起動したのに、画面が出ません | すでに動いています(トレイに常駐しています)。ショートカットキーか、トレイのアイコンで出します。二重には起動できません |
| 「Windows によって PC が保護されました」と出ます | コード署名が無いためです。[上の案内](#smartscreen-の警告について)のとおり、「詳細情報 → 実行」で続けられます |
| 起動時に自動で起動してほしい | 設定の「Windows 起動時に自動で起動する」をオンにします(初期はオフです) |
| 不具合が起きました | `%AppData%\AlumiLauncher\logs\alumi.log` に、原因が残っていることがあります。下の「不具合・要望の連絡」を見てください |
