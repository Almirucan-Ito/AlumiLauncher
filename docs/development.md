# 開発の手引き(ビルド・規約・ソースの場所・ひな形)

はじめに [CONTRIBUTING.md](../CONTRIBUTING.md) を読んでください(環境・コマンド・チェックリスト)。構造は [architecture.md](architecture.md)、拡張の作り方は [extending.md](extending.md) です。

## ビルド

環境のつくり方は [setup.md](setup.md)、ビルドの詳しい手順(ビルド前の確認・バージョン・ポータブル版・オフライン版・WSL からのビルド・困ったとき)は [build.md](build.md) にあります。

```powershell
npm ci
npm run tauri dev      # 開発
npm run tauri build    # インストーラーを作成(src-tauri/target/release/bundle/nsis/)
.\scripts\release.ps1            # インストーラー+チェックサムを release/ に作成
.\scripts\release.ps1 -Zip       # 上に加えて、ポータブル版 zip(AlumiLauncher_Portable.zip)も作成(配布するときは、こちら)
.\scripts\release.ps1 -Offline   # 上に加えて、オフライン版(WebView2 同梱)も作成
```

### コード署名(任意)

SmartScreen の警告をなくすには、コード署名証明書での署名が必要です(Azure Trusted Signing、OV/EV 証明書など)。
証明書を用意できたら、`src-tauri/tauri.conf.json` の `bundle.windows` に
`certificateThumbprint` / `digestAlgorithm` / `timestampUrl`(または `signCommand`)を設定してビルドしてください。
署名しても、新しい証明書では SmartScreen の評価が貯まるまで警告が出ることがあります。

## コーディング規約

機械で確認できる形にしてあります(設定ファイルがルールそのものです)。

| 対象                             | ツール                                 | 設定                     | 実行                                                |
| -------------------------------- | -------------------------------------- | ------------------------ | --------------------------------------------------- |
| 共通(改行 LF・UTF-8・インデント) | EditorConfig                           | `.editorconfig`          | エディタが自動で従う                                |
| TypeScript / React の整形        | Prettier                               | `.prettierrc.json`       | `npm run format`(確認だけは `npm run format:check`) |
| TypeScript / React の検査        | ESLint(typescript-eslint・react-hooks) | `eslint.config.js`       | `npm run lint`(自動修正は `npm run lint:fix`)       |
| 型                               | tsc(strict・未使用は禁止)              | `tsconfig.json`          | `npm run build`                                     |
| Rust の整形                      | rustfmt                                | `src-tauri\rustfmt.toml` | `cargo fmt`                                         |
| Rust の検査                      | clippy(警告ゼロ)                       | -                        | `cargo clippy -- -D warnings`                       |

- 全部まとめて確認: `npm run check`(tsc + ESLint + Prettier + ミニアプリ・ウィジェットの検査 + 画面のテスト)
- 関数・定数・型には、日本語の説明コメント(TypeScript は JSDoc、Rust は `///`)を付けます。
- ミニアプリ・ウィジェットの HTML・CSS・ブラウザ用の JavaScript(`src\miniapps`・`src\widgets`)は、本体とは独立しているため、ESLint の対象外です(HTML 以外の CSS・JavaScript は、Prettier で整形します。HTML は、空白で見た目が変わることがあるため、手で整えます。ESLint の代わりに `npm run check:miniapps` で、JSON・ファイルの有無・JavaScript の文法を、`npm run check:js` で、存在しない名前の使用(書き間違い)を検査します)。ランチャー側の TypeScript(`index.tsx` など)は、本体と同じ規約です。

## ソースコードの場所

すべての関数・クラスに、日本語の説明コメント(引数・戻り値つき)があります。

| 場所                                      | 内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `src\launcher\`                           | ランチャー本体(React / TypeScript)。機能ごとのフォルダに分けてあります。入口は `main.tsx`・`App.tsx`                                                                                                                                                                                                                                                                                                                                                                                                               |
| `src\launcher\modules\`                   | 機能ごと。`home\`(ホーム)、`folders\`(フォルダ)、`settings\`(設定の画面)、`widgets\`(ウィジェットの欄・追加画面・置き場所)、`miniapps\`(ミニアプリの窓口・アラーム)、`start-apps\`(スタートメニューから追加)、`icons\`(アイコン)、`plugins\`(ミニアプリ・ウィジェットを自動で集める仕組み)                                                                                                                                                                                                                         |
| `src\launcher\shared\`                    | 機能をまたぐ部品。`api\`(Rust との通信・型・保存データ)、`ui\`、`drag\`、`audio\`、`i18n\`(文言)、`styles\`、`lib\`(小さな道具)                                                                                                                                                                                                                                                                                                                                                                                    |
| `src-tauri\src\`                          | 本体(Rust)。機能ごとのフォルダに分けてあります。`config\`(設定の型・保存・検査)、`files\`(フォルダ・ファイルの操作と起動)、`extensions\`(ミニアプリ・ウィジェット。同梱・データ・Web ミニアプリ)、`window\`(ウィンドウ・ショートカットキー・トレイ・デスクトップモード)、`platform\`(Windows のアイコン・ドラッグ・スタートメニュー)、`state.rs`(共有の状態)、`tests\`(テスト。`config.rs`・`files.rs`・`extensions.rs`・`window.rs` に、機能ごとに分けてある)。`lib.rs` は、入口(`run`)と、コマンドの登録だけです |
| `src\miniapps\`                           | 同梱のミニアプリ(メモ・ミュージック・予定とToDo・時計とタイマー・電卓・全体検索・画像ビューア・ラッキーラッシュ)。1 フォルダ = 1 アプリで、`view\`(画面)と `controller\`(動き)に分けてあります。ミュージックだけは、ランチャー側の部品(音楽プレーヤー本体)も、このフォルダの中にあります                                                                                                                                                                                                                           |
| `src-tauri\installer\`・`tauri.conf.json` | インストーラーの設定                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `scripts\release.ps1`                     | ビルドと配布物の作成                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `src\widgets\`                            | 同梱のウィジェット(時計・よく使うもの・最近開いた・検索・ToDo・タイマー)。1 フォルダ = 1 つ。`_examples\` は自作用の見本(ミニアプリの見本は `src\miniapps\_examples\`)                                                                                                                                                                                                                                                                                                                                             |

## ウィジェット・ミニアプリの独立性と削除

ウィジェット・ミニアプリは、それぞれ 1 つのフォルダ(`widgets\<名前>` / `miniapps\<名前>`)で完結していて、ランチャー本体とは別に動きます(sandbox 付きの画面で、本体の機能・設定・ファイルには、許可した機能だけを通して触れます)。**フォルダを削除しても、ランチャー本体は、不具合なく動き続けます。**

| 削除したもの                       | 起きること                                                                                                                                                                                                            |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ミニアプリ(例: 画像ビューア)       | 一覧から消えます。ホームに置いた、そのミニアプリのアイコン(`.alumiapp`)は、標準のアイコンになり、押すと「見つかりません」と出ます(アイコンは、手で消してください)。そのミニアプリの中のウィジェットも、一緒に消えます |
| ミニアプリ「ミュージック」         | 「ミュージック」のウィジェットも消えます。音楽プレーヤー本体は、ランチャー側にあるので、残ります(曲の一覧は、ミュージックのフォルダに保存されているので、削除すると消えます)                                          |
| ミニアプリ「予定とToDo」           | 「ToDo」ウィジェットは、データの置き場所がなくなるので、一覧にも欄にも出なくなります(欄に空きだけが残ることはありません)                                                                                              |
| ウィジェット(`widgets\<名前>`)     | 一覧と欄から消えます。設定には ID が残るので、フォルダを戻せば、また出ます                                                                                                                                            |
| 同梱のもの(メモ・ミュージックなど) | 削除したものは、次の起動でも、戻りません(戻したいときは、`widgets` と `miniapps` の中の `.alumi-seeded` を削除して、再起動します)。アプリを更新したときも、削除したものは作り直しません                               |

- 同意の記録(外部との通信を許可したもの)は、削除しても、設定に残ります(設定の「外部との通信を許可したもの」から消せます)。
- データ・キャッシュは、それぞれのフォルダの中(`data` / `cache`)にあるので、フォルダと一緒に消えます。ほかのフォルダのデータには、影響しません。

## 新しく作る(ひな形)

同梱のものと同じ作りの、ひな形があります。フォルダごとコピーして、名前と中身を書き換えるだけで、似たソースで作れます(日本語のコメント付き)。

- ミニアプリ: `src\miniapps\_examples\template-app\`(`miniapp.json` / `icon.svg` / `view\index.html`・`view\style.css` / `controller\main.js`)
- ウィジェット: `src\widgets\_examples\template-widget\`(`widget.json` / `view\index.html`・`view\style.css` / `controller\main.js`)

並びは、どちらも「窓口 → 小さな道具 → 状態 → 描画 → 操作 → 起動」です。コピーしたフォルダを、ランチャーの画面へドラッグ&ドロップすると、取り込まれます。
