# 手動確認の一覧

自動のテスト(`npm run check`)では確かめられない、Windows の実機での確認項目です。リリース前に、`scripts\release.ps1` で作った exe で一通り確認してください。

## 通常版(インストーラー)

- [ ] 初回起動で、**Windows 起動時の自動起動がオフ**になっている(設定 → スタートアップ。タスクマネージャーの「スタートアップ」にも出ない)
- [ ] 設定でスタートアップをオンにして、Windows にサインインし直すと、起動する。オフに戻すと、起動しない
- [ ] 「デフォルト値にする」でスタートアップがオフになる
- [ ] ショートカット(既定 `Ctrl+Alt+L`)で表示/非表示。トレイのアイコンからも切り替えられる
- [ ] 「アプリを終了する」(2 回押し)で、トレイからも消えて終了する
- [ ] 2 つ目を起動しようとすると、新しく開かず、いまのウィンドウが前に出る
- [ ] 設定・ホームの並びが、終了 → 再起動のあとも残っている

## ポータブル版

ポータブル版は、インストールせずに使う版です。`release.ps1 -Zip` が作る zip の中に、exe と `portable.txt` が入っています。`portable.txt` が exe の隣にあると、設定・ホーム・ミニアプリ・ウィジェット・記録(ログ)・WebView2 のデータは、すべて exe の隣の `data` フォルダに保存されます(レジストリや `%AppData%` には書きません)。

- [ ] zip を空のフォルダに展開して起動すると、`data` フォルダが exe の隣にできる
- [ ] 設定を変えて終了 → 再起動しても、残っている
- [ ] フォルダごと別の場所へ移して起動しても、設定が引き継がれる
- [ ] `%AppData%\AlumiLauncher` にも `%LocalAppData%` の WebView2 のフォルダにも、ファイルが増えていない
- [ ] 通常版が入っている PC でも、ポータブル版のデータは通常版と混ざらない

## デスクトップモード

(デスクトップモードは、ウィンドウを最大化して、一番後ろに固定する、疑似的なものです。Windows のデスクトップそのものの置き換えでは、ありません。)

- [ ] 常に最背面・最大化固定で、閉じる・最小化・最大化のボタンが消える
- [ ] 画面をクリックすると操作できて、他のアプリを選ぶと、また最背面へ戻る
- [ ] 最大化してからデスクトップモードをオン → オフにすると、最大化の状態に戻る
- [ ] オフにした直後、すぐにこのアプリが選択された状態になる(ラグがない)
- [ ] `Win + D` のあとの挙動(最背面に残るかは、未対応。現状は他のウィンドウと同じ)

## ホーム・スタートメニュー

- [ ] 「スタートメニューから追加」で、一覧が出て、選んだアプリがホームに追加される。起動できて、アイコンも出る
- [ ] エクスプローラーからのドロップで、ファイル・フォルダが追加される
- [ ] ホーム ↔ フォルダの間のドラッグで、移動できる

## 記録(ログ)と保存の失敗

- [ ] `%AppData%\AlumiLauncher\logs\alumi.log` がある。起動の行(`起動 v…`)がある
- [ ] 設定ファイルを読み取り専用にして設定を変えると、「設定を保存できませんでした」と表示され、ログに `設定の保存に失敗` が残る。読み取り専用を外すと、次の保存で書ける
- [ ] 記録の内容は、この PC の中だけにあり、どこにも送られない(ネットワークは `127.0.0.1:9` へ向けて遮断されている)

## ミニアプリ・ウィジェット

- [ ] 同梱のミニアプリが、初回の同意のあとに開く。同意しないと開かない
- [ ] ウィジェットを足す・消す・並べ替えができ、再起動後も残る
- [ ] 「ウィジェットを追加」「ミニアプリを追加」の画面が、ウィンドウを狭くしても(横 580px くらい)、ウィンドウの中央に出て、右へはみ出さない

## 右クリックメニュー

- [ ] アイコンの右クリック →「プログラムから開く…」で、アプリを選ぶ画面が出る(選んだアプリで開く)
- [ ] 「プロパティ」で、Windows のプロパティの画面が出る(アイコンにも、フォルダにも)
- [ ] 設定の一番下に、バージョンが出ている

## ウィジェットのマスと「ショートカット」

- [ ] ヘッダー・フッターのウィジェットを動かすとき、マスの目印が、横に長い四角(高さ 44px・横幅は広いウィンドウで 72px)で出る
- [ ] ウィンドウの幅を広げると、ヘッダー・フッターの横幅も広がり、7 マス全体で約 530px(横幅 72px のマス)で止まる。高さ(44px)は変わらない。設定のアイコンの大きさを変えても、ウィジェットの大きさは変わらない。ウィンドウが狭いときは、マスの横幅が縮み、とても狭いときは、高さも縮んで正方形になる
- [ ] ヘッダー(フッター)の何もない所を右クリックして、「高さ: 小(1 マス)/ 標準(2 マス)/ 大(3 マス)」を選べる(✓ が付く)。段の中のウィジェットが、すべて、その高さになる。ウィジェットを右クリックしても、高さは出ない(幅・移動・外すだけ)
- [ ] ウィジェットを動かしている間の、マスの目印が、横 7 マス × 高さのぶん(小=1 行・標準=2 行・大=3 行)で、すべて同じ大きさ。落とす場所の枠も、その高さ
- [ ] 中身が、高さに合わせて切り替わる(小のミュージックは、曲名と再生ボタンが 1 行)
- [ ] ヘッダー・フッターの高さが、ウィジェットの高さに合わせて変わる。ウィジェットを外すと、ヘッダー(フッター)が消えて、ホームが広がる
- [ ] 上から、トップ(プリセットとウィンドウのボタン)・ヘッダー・ホーム・フッター・ボトム(＋・再読み込み・設定)の順に並び、重ならない
- [ ] ヘッダーに、スクロールバーが出ない
- [ ] ヘッダー・フッターが、横 7 マスで、中心(4 マス目)が、ウィンドウの中心と合っている
- [ ] 「ショートカット」ウィジェットへ、ホームのアイコン・フォルダをドラッグすると、枠が出て、離すと入る(ホームには、元のものが残る)
- [ ] ウィジェットの中のアイコンを押すと起動し、フォルダを押すと、フォルダが開く。フォルダのアイコンは、ホームと同じ(中のアイコンを 9 マスで見せる)
- [ ] 「ショートカット」のアイコンを右クリックして、「〜を外す」で外せる。アイコンをドラッグして、順番を変えられる(離した位置に入る。ドラッグしたあとに、アプリが起動しない。長押しでウィジェットごと動いたりしない)
- [ ] ホームのアイコン・フォルダを消す(一覧から外す・フォルダへ移す)と、ショートカットウィジェットからも消える。ミニアプリは、ホームのアイコンを消しても残り、ミニアプリのフォルダから消すと(再起動か、ミニアプリの一覧を開き直すと)消える
- [ ] 高さ 小・標準: 1 段で、6 個まで(7 個目を落とすと、「6 個まで」と出る)。標準は、小よりアイコンが大きい(幅が 7 マスのとき)。大: 2 段で、12 個まで。大から小にしても、入れたものは消えず、大に戻すと、また出る
- [ ] 同じものを、もう一度落とすと、「もう入っています」と出る。アプリを再起動しても、残っている
- [ ] ヘッダーのウィジェットの上の部分も、クリックできる(タイトルバーに隠れない)
