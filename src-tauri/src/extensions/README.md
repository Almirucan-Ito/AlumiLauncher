# extensions(ミニアプリ・ウィジェット)

ミニアプリ・ウィジェットを、一覧にする・同梱する・取り込む・ファイルを渡す・データを預かる、を受け持ちます。画面側の窓口は `src/launcher/modules/miniapps`・`widgets`。

## 担当すること

- `widgets/`: 追加ウィジェットとミニアプリのマニフェスト(`widget.json` / `miniapp.json`)を読んで一覧にする(`scan.rs`)、ドロップされたフォルダの取り込み(`install.rs`)、
  名前・URL・パスの検査(`paths.rs`)、アイコン(`icons.rs`)、`widget://` / `miniapp://` の応答(`protocol.rs`: ファイルの配信・CSP・外部通信の許可)。
- `bundled.rs`: 同梱のミニアプリ・ウィジェット(`build.rs` が作る一覧)を、起動時に書き出す。
- `catalog.rs`: 一覧・フォルダを開く・取り込み・ホームのショートカット作成のコマンド。
- `appdata.rs` / `storage.rs`: ミニアプリ・ウィジェットのデータ(`data`)とキャッシュ(`cache`)の読み書き・大きさの取得・消去。
- `music.rs` / `media.rs`: ミュージック・画像ビューアが使う、ローカルの音声・画像ファイルの「登録」(印を渡す)と、配信。
- `mini_web.rs`: Web ミニアプリ(URL を開くもの)の別ウィンドウ(位置合わせ・音量・閉じる)。

## 担当しないこと

- ミニアプリ・ウィジェットの中身(`src/miniapps`・`src/widgets`)。
- 画面側の `postMessage` の窓口と、権限の確認(画面の `modules/miniapps/miniapp.tsx`)。Rust は、ファイルとデータを渡す側。

## 設計の理由

- **ファイルは、フォルダの外へ出さない**(`protocol.rs` の `respond`): `..`・リンク・フォルダでないもの・大きすぎるファイルには、404 を返す。
  パスは `canonicalize` して、そのミニアプリのフォルダの中かを確かめる。名前(`valid_id`)も検査する。
- **外部との通信は、2 つの条件がそろったときだけ開く**(`network_ok`): マニフェストが `"network": true` と宣言し、かつ、利用者が同意した(設定の `networkAllowed` にキーがある)。
  応答の CSP(`Content-Security-Policy`)は、そのときだけ通信を許す内容にする。
- **音声・画像は、「登録した印」のファイルだけ渡す**(`music.rs`): 任意のパスは渡さない。登録できるのは、実在する音声・画像のファイル(拡張子で判定)だけ。
- **データは、キー 1 つにつき、`<キー>.txt` のファイル 1 つ**(`appdata.rs`): キー名は、英数字と `_ - .` で 64 字まで、先頭は `.` にしない(ファイル名になるため)。
  値は 64KB まで、1 つのフォルダに作れるキーは 64 個まで。消えても困らない、作り直せるものは、`cache` に置く。画像の見本のキャッシュには、上限がある(200MB)。
- **同梱のものは、実行ファイルの中に埋め込み、起動時に書き出す**: 埋め込みは `build.rs` が `src/miniapps/*`・`src/widgets/*` から作る(フォルダを足すだけで同梱される)。
  **版は、埋め込む内容のハッシュ**なので、内容を変えれば、次の起動で自動で書き換わる(`data` の保存データは残る)。
  - フォルダが無い、または版の印(`.alumi-bundled`)が違うときだけ、書き出す。同じ版なら、利用者が書き換えた内容を、そのまま残す。
  - **利用者が削除したものは、作り直さない**: 一度書き出したものを `.alumi-seeded` に記録している。これを消すと、削除した同梱のものが、次の起動で戻る。
- **ウィジェット一覧の検査に使う `builtin` の種類(許可リスト)も、`build.rs` が `widget.json` から作る**ので、Rust を書き換える必要がない。

## 触るときの注意

- 新しい権限を足すときは、`schemas/miniapp.schema.json` に足し、画面側の窓口(`miniapp.tsx` か、ミニアプリの `bridges`)も実装する(足し忘れは、テストが知らせる)。
- テストは `src-tauri/src/tests/extensions.rs`・`widgets/tests.rs`・`appdata_tests.rs`(マニフェストの検査・パスの安全性・保存・同梱の定義)。
- `mini_web.rs` の上のバーの高さ(`MINI_BAR_HEIGHT`)は、画面の `.mini-bar`(`shared/styles/miniapps.css`)と同じ値にする。
