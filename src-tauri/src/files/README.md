# files(フォルダとファイルの操作)

ホームとフォルダの中身の一覧、ファイルの移動・追加・新規作成・名前の変更・削除・起動、背景画像を受け持ちます。

## 担当すること

- `listing.rs`: ホームとフォルダの中身の一覧(アイコンの並び・隠しファイルの除外・アイコン画像)と、`launcherFolder`(ホームに直接置いたアイコンの保存先)の場所。
- `operations.rs`: ファイルの移動・追加・フォルダの作成・名前の変更(`rename_item`)・削除(ごみ箱へ)。
- `text_files.rs`: テキストファイル(`.txt` / `.md`)の作成・読み書き。
- `usage.rs`: 起動(`launch`)と、起動の記録(「よく使うもの」「最近開いた」)。
- `shell_ops.rs`: エクスプローラーで開く・プロパティ・「プログラムから開く」。
- `background.rs`: 背景画像の取り込み・読み込み、Windows のテーマカラー。
- `roots.rs`: **操作してよいフォルダ**(登録フォルダと `launcherFolder`)の管理と、その見張り(外での変更を、画面へ知らせる)。

## 担当しないこと

- Windows のシェルの低い層(アイコンの取り出し・ごみ箱・ドラッグ。`platform/`)。ここは、それを呼ぶ。
- 画面の並び順・履歴(画面側)。ここは、実際のファイルを動かすだけ。

## 設計の理由

- **触ってよいのは、登録フォルダの中だけ**: 画面から任意のパスを、実行・削除・読み取り・名前の変更されないよう、操作の前に `in_registered` で確かめる。
  パスは `canonicalize` して比べるので、リンクを使った抜け道も防げる。存在しないパスは、断る。
  ドライブ直下と Windows のフォルダは、そもそも登録できない(`is_allowed_folder`)。
- **削除は、完全な削除ではなく、ごみ箱へ**(確認ダイアログは出さない。画面側で確認する)。
- **名前の変更の決まりは、画面と同じ**(`check_new_file_name`): 空・前後の空白・終わりの `.`・使えない文字・Windows が使う名前(`CON` など)・長さ(200 字)を断る。
  **拡張子は変えられない**(ファイルの種類のすり替えを防ぐ)。同じ名前の別のファイルがあるときは、上書きせず、`exists` のエラーを返す。
  大文字・小文字だけの変更は、できる。画面側の `modules/folders/ItemNameModel.ts` と**同じ決まりにする**。
- **見張りは、パスが前と同じなら作り直さない**(`restart_watcher`): 並べ替えのたびに作り直さないため。
  ミニアプリのフォルダは、直下の増減だけを見る(ミニアプリのデータ・キャッシュは、中で頻繁に書き換わるため)。読み取りだけの変化は、無視する。
- **パスの比較は、小文字・`\` にそろえて行う**(`norm_path`): Windows は、大文字・小文字を区別しないため。`C:\a` が `C:\ab` に当たらないよう、`\` を付けて比べる。
- **起動の記録は、パスで持つ**ので、名前を変えると、数え直しになる。書き込みは、まとめて行う(`schedule_flush`)。
- **ホームの並びのキー `HOME_ORDER_KEY` は、画面と同じ値**(`rust-sync.test.ts` が、ずれを知らせる)。

## 触るときの注意

- 新しいファイル操作のコマンドは、必ず `in_registered` を通す(`allow_root` で、登録フォルダ自身を許すかを決める)。
- テストは `src-tauri/src/tests/files.rs`(名前の検査・名前の変更・移動など。実際に、一時フォルダでファイルを動かす)。
