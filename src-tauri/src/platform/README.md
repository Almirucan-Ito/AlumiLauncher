# platform(Windows のシェルの機能)

アイコンの取り出し・ファイルのドラッグ・スタートメニューのアプリ・ごみ箱・表示言語の判定など、Windows のシェル(エクスプローラーの仕組み)を使う機能です。

## 担当すること

- `icon/`: ファイル・ショートカットのアイコン(最大 256px)を、Windows シェルから取り出して PNG にする(`mod.rs`)。画像・動画のサムネイルも。
  - `pixels.rs`: 画素(RGBA)の加工(絵の部分の切り出し・縮小・なめらかな拡大・PNG にする)。**Windows の機能を使わない、純粋な計算**。
- `dragout.rs`: アプリのアイコンを、デスクトップやエクスプローラーのフォルダへドラッグして移動する(Windows 標準のドラッグ&ドロップ)。
- `startmenu.rs`: スタートメニューのアプリ(通常のアプリ・ストアアプリ)の一覧と、ショートカットの複製。
- `shortcut.rs`: ごみ箱への移動・プロパティなどのシェルの動詞、Windows のテーマカラー(アクセントカラー)。
- `locale.rs`: Windows の表示言語の判定(トレイのメニューと初期フォルダの名前を選ぶのに使う)。
- `commands.rs`: 上のうち、画面から呼ぶコマンド(`start_file_drag`・`list_start_apps`・`add_start_app`・`write_log`)。

## 担当しないこと

- 「どのファイルに触ってよいか」の判断(`files/roots.rs`)。ここは、触る処理だけで、呼ぶ側が、先に確かめる。
- ファイルの一覧・移動・名前の変更(`files/`)。

## 設計の理由

- **アイコンは、最大 256px のまま使う**: 小さく縮めると、ぼやけるため。元のアプリが小さいアイコン(48px など)しか持たないときは、
  画面で引き伸ばされてギザギザにならないよう、先に、なめらかに(バイキュービックで)拡大する。
- **画素の加工は、Windows の機能から切り離す**(`pixels.rs`): `mod.rs` が、取り出したアイコンの画素を渡すだけの、純粋な計算にして、テストしやすくしてある。
- **スタートメニューの一覧は、`shell:AppsFolder` から読む**: スタートメニューに出るものと同じ。複製は、そのアプリのシェル上の位置(ID リスト)を書いた `.lnk` を作る
  (エクスプローラーの「ショートカットの作成」と同じ)。元のアプリ・スタートメニューは、そのまま。
- **ごみ箱への移動は、確認ダイアログを出さない**(`FOF_ALLOWUNDO | FOF_NOCONFIRMATION`): 確認は画面側で行う。完全な削除はしない。
- **`unsafe` には、`// SAFETY:` で、安全である理由を書く**。COM は、`ensure_com` で用意してから使う。

## 触るときの注意

- Windows 専用の部分は `#[cfg(windows)]`。Linux で clippy を通すために、`--target x86_64-pc-windows-msvc` を付ける。
- 実機でしか確かめられない(エクスプローラーへのドラッグ・スタートメニューの追加・アイコンの見た目)ので、`docs/manual-test.md` を見る。
