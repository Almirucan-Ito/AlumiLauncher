# modules/home(ホーム画面)

最初に見える画面です。フォルダと、ホームに直接置いたアイコンを並べ、ドラッグでの並べ替え・フォルダへの出し入れ・検索を受け持ちます。

## 担当すること

- **ホームの並び**: `useHomeEntries`(フォルダ + ホームに直接置いたショートカットを、ドラッグで変えた順 `HOME_ORDER_KEY` に並べる)、`HomeModel`(並びの計算)。
- **画面と右クリック**: `HomeScreen`、`useHomeMenus`(アイコン・フォルダ・何もない所の右クリックメニュー)。
- **ホームとフォルダ内のドラッグの受け渡し**: `useDragHandover`(フォルダの上で止めると開き、そのまま中に入れる。フォルダの外へ出して止めると、ホームへ置く)。
- **エクスプローラーからのドロップ**: `useExplorerDrop`(ウィジェット・ミニアプリのフォルダは取り込み、ファイルは `launcherFolder` へ移してホームに並べる)。
- **検索**: `useHomeSearch`(検索ウィジェットの入力で、名前を絞り込む)。

## 担当しないこと

- フォルダを開いた画面・フォルダの操作・名前の変更(`modules/folders`)。
- ページ送りの一覧そのもの(`shared/ui/Pager`)。ホームは、それを使って並べるだけ。
- ウィジェットの欄(`modules/widgets`)。ただし、ウィジェットの上へ落とすドラッグは、`useWidgetDrop` が受ける。

## 設計の理由

- **ホームに直接置いたアイコンは、本物のファイル(ショートカット)**: Rust 側の `launcherFolder` に保存される。
  フォルダは設定(`config.json`)の `folders` に持つ。どちらも「ホームに並ぶもの」なので、`HomeEntry` に、`folder` と `item` を並べて持つ。
- **並び順は、識別子の一覧で持つ**(`entryKey`: フォルダは `f:<ID>`、ショートカットは `i:<パス>`)。一覧に無いもの(新しく増えたもの)は、元の順のまま後ろへ。
  キー `__home__`(`HOME_ORDER_KEY`)は、Rust 側(`files/listing.rs`)と**同じ値にする**(`rust-sync.test.ts` が、ずれを知らせる)。
- **`slot`(空き)は、描画だけに使う**: フォルダ内から持ち出したアイコンを置く場所を、周りのアイコンがよけて空けるための仮のもの。並びのデータには入れない。
- **ウィンドウは、アイコンが揃ってから出す**: `useHomeEntries` が、設定・ホームの一覧・アイコンが揃うまで待って(最大 3.5 秒)から `appReady` を呼ぶ。
  アイコンが途中で入れ替わって見えないようにするため。
- **計算は `HomeModel` に分ける**(`insertClamped`・`clampSlot`・`folderUnderPoint`)。ドラッグは自動のテストが薄いので、計算だけでも vitest で固める。

## 触るときの注意

- ドラッグの判定の数値(重ねる範囲・待つ時間など)は、`shared/api/TuningModel.ts` にある。ここに直接書かない。
- `useDragHandover` は、状態が多く、いちばん壊れやすい。直したら、`docs/manual-test.md` の「ホーム・スタートメニュー」と、ドラッグの項目を、実機で確かめる。
- 並びを変える操作は、元に戻せるように、`modules/history` の `snapshot` / `pushHistory` を通す。
