# modules/start-apps(スタートメニューから追加)

「スタートメニューから追加」の画面(`StartAppPicker`)だけの、小さなフォルダです。

## 担当すること

- Windows のスタートメニューのアプリ(通常のアプリ・ストアアプリ)の一覧を出し、名前で絞り込む。
- 選んだアプリのショートカットを、ホームに複製して追加する(続けて何個でも追加できる。「完了」で閉じる)。

## 担当しないこと

- 一覧の取得と、ショートカットの作成(Rust の `platform/startmenu.rs`。`shell:AppsFolder` から読み、アプリのシェル上の位置を書いた `.lnk` を作る)。
- 追加したあとのホームの更新(呼ぶ側が、`onAdded` で受け取って、表示を更新する)。

## 設計の理由

- **元のアプリ・スタートメニューは、そのまま**: 複製したショートカットを、ホームの保存先に置くだけで、元のものは、動かさない・消さない。
- **一覧を開いたときに、一度だけ読む**: 失敗の通知は、そのときの最新の関数で行う(`useLatest`)。
- この画面は、`shell/Pickers` が出す(追加の画面は、ウィジェット・ミニアプリ・これの 3 つを `Pickers` がまとめる)。
