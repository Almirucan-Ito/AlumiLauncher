# modules/widgets(ウィジェットの欄)

ホームの上(ヘッダー)と下(フッター)の、ウィジェットを並べる欄です。置き場所の計算・追加・移動・大きさの変更・追加の画面を受け持ちます。

## 担当すること

- **置き場所の計算**: `LayoutModel`(画面を使わない計算。マスの数・大きさ・重ならない置き場所・幅の範囲)。
- **欄の描画**: `AppWidgetBar`(ヘッダー・フッターの出し入れ)、`WidgetBar`(欄の中の描画・動かしている間の目印)。
- **操作**: `useWidgetBars`(追加・移動・幅の変更・右クリックメニュー・欄の高さ)、`useWidgetDrop`(ホームのアイコン・フォルダを、ウィジェットの上へ落とす)。
- **一覧と追加画面**: `useWidgetList`(ウィジェットの一覧)、`WidgetPicker`(追加の画面)、`useWidgetEnv`(ウィジェットへ渡す窓口 `WidgetEnv` を作る)。

## 担当しないこと

- 個々のウィジェットの中身と見た目(`src/widgets/<名前>/`。時計・ToDo・タイマーなど)。ここは、枠と置き場所だけ。
- ウィジェットを取り込む・一覧を作る処理(Rust の `extensions/`)。
- ウィジェットの部品を名前で読み込むこと(`modules/plugins/PluginRegistry` を通す)。

## 設計の理由

- **欄は、横 7 マスで固定、中心は 4 マス目**(`COLS`)。ウィジェットは、開始のマス(`col`)と幅(`span`)で置き、重ならない。
  標準の幅は、中心に、ぴったり置けるよう、奇数にしてある。
- **マスの高さは、固定(44px)**(`CELL_SIDE`): 設定のアイコンの大きさや、ウィンドウの大きさでは、変えない。ウィジェットの高さ(1・2・3 マス = 44・92・140px)が、これで決まる。
  マスの横幅は、広いウィンドウでは 72px(`CELL_WIDTH`)まで広がり、狭いときだけ縮む。
  この値は JS(`cellWidth` / `cellSide`)が計算し、CSS には `--wcell`・`--wcol` の変数で渡す(`shared/styles/widgets.css` は、その変数を使う)。
- **ウィジェットの高さは、欄で 1 つ**(小・標準・大): 欄の中のウィジェットは、すべて同じ高さ。選べるのは、この 3 つだけ。
- **中身は、高さに合わせて切り替える**(CSS の `@container`): `.widget` が、幅と高さを測る入れ物になる。各ウィジェットの CSS が、それぞれの切り替えを書く。
- **計算は `LayoutModel` に分け、`vitest` で試す**(`LayoutModel.test.ts`)。ドラッグで動かす部分は、自動のテストが薄い。
- **ウィジェットへは、内部をそのまま渡さず、`WidgetEnv` だけ渡す**(`modules/plugins/PluginModel.ts`)。

## 触るときの注意

- マスの数・大きさを変えるときは、`LayoutModel` の定数と、`docs/manual-test.md` の「ウィジェットのマスと『ショートカット』」を、いっしょに見直す。
- 小さいウィンドウ(`BARS_MIN_HEIGHT`・`BARS_MIN_WIDTH` 未満)では、欄を出さない。この値は `shell/useWindowMode` が使う。
- 設定にある「置き場所」は、一覧に無いウィジェット(フォルダを消した)も残す。フォルダを戻すと、また出る(欄の描画では、数えないだけ)。
