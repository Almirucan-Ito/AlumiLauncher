# shared/audio(合図の音)

終わりの合図(短い 3 音のチャイム)を鳴らす `BeepController` だけの、小さなフォルダです。アラームやタイマーの終わりに使います。

## 担当すること

- `beep()`: 合図を鳴らす。音量は、`setBeepVolume` で決める(`App` が、設定の「音量」が変わるたびに渡す)。

## 担当しないこと

- 音楽の再生(ミニアプリ「ミュージック」。`src/miniapps/music`)。

## 設計の理由

- **音源のファイルを使わず、その場で作った単純な正弦波を鳴らす**(Web Audio): 著作権・ライセンスの問題がない。ファイルも増えない。
- **音が出せない環境では、何もしない**(`try` で囲んでいる)。音量が 0 のときも、何もしない。
